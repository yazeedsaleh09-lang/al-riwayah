# Repository Audit Skill

## Trigger
Beginning work or resuming after uncertain state.

## Procedure
1. Read execution pack.
2. Capture Git status/diff/log.
3. Inventory files/scripts/routes/config.
4. Run existing gates without changing code.
5. Classify failures: pre-existing, environment, introduced, unknown.
6. Record baseline in PROGRESS.
7. Never delete unknown files.

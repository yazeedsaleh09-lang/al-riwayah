Research date: 2026-07-28
Scope: mobile product flows, complete-site composition, and mood/material discovery for an Arabic-first, phones-only social thriller party game.

This is a translation matrix, not a look-book. A useful reference earns its place by resolving a specific product problem. No layout, asset, copy, identity, or interaction is approved for direct reuse.

## Access and evidence limits

- **Mobbin:** its public site and MCP description were accessible, but screen-level search and MCP access require a paid plan. No Mobbin app screen, flow, or image was viewed through an authenticated account. Entries below therefore use accessible first-party product documentation for screen-level evidence and use Mobbin only as a flow-comparison method.
- **Awwwards:** public listings and some element pages were accessible. Several full site-detail pages timed out. Where that happened, the creators' or brands' live pages were used as the primary source and the Awwwards URL is retained only as an award/index pointer.
- **Cosmos:** public collection titles and some cover metadata were accessible; many individual saves and provenance details require JavaScript or sign-in. No Cosmos image is approved as an asset.
- **Pinterest:** direct access returned HTTP 403. The query URLs below are recorded as tightly scoped manual-discovery queues, not as observed visual evidence. No pin was downloaded, selected, or treated as licensed.
- **Live visual inspection:** the available in-app browser reported no usable browser backend in this session. Composition findings are limited to accessible page structure, image metadata, public element descriptions, and first-party case-study text.

## Exact UI terminology to carry into implementation and tests

Use these names consistently:

- **room-code entry form** with a persistent **label**, **helper text**, and **inline validation message**
- **native share sheet** (Apple: **activity view**) with a **copy fallback**
- **modal bottom sheet** only for a short, interruptible mobile subtask
- **bottom action bar** for a persistent, thumb-reachable primary action; do not call it bottom navigation
- **player roster**, **ready state**, **connection status**, and **host badge** in the lobby
- **determinate progress ring** or **linear progress bar** for a known deadline; **spinner** only for an indeterminate wait
- **skeleton screen** for a known incoming layout; **empty state** only when content is truly absent
- **toast (snackbar)** for brief non-blocking confirmation; persistent failures need an inline error or status banner
- **radio group** for exclusive answer selection; **toggle group (segmented control)** only for switching a setting or view
- **carousel** only when content is paged one item at a time; a free-scrolling preview strip is a **gallery rail**
- **sticky** narrative stage within its section; **fixed** controls only when they must remain anchored to the viewport
- **focus ring (`:focus-visible`)** for keyboard focus
- **result summary** followed by a causal **result timeline** and clear **replay/new-group actions**
- **reconnect overlay** for a recoverable transport interruption; do not mislabel it as an empty state

## Decisions this matrix supports

1. **Product flow:** join and create remain single-purpose screens; lobby state is explicit; share uses the native sheet plus copy fallback; reconnect is a persistent recoverable state.
2. **Marketing composition:** the hero must show real representative product UI at meaningful scale; each following section changes compositional job; the total story remains concise.
3. **Signature system:** Versioned Testimony—one aligned Arabic statement, one
   displaced clause, and one written reason—becomes the repeatable visual
   mechanism. No circular table, orbit, or seat map is permitted.
4. **Motion:** one state-changing focal motion per section; tap, keyboard, and reduced-motion alternatives are first-class.
5. **Assets:** original CSS/SVG/Canvas and live UI are the default. No image from a discovery platform proceeds without original-source and license verification.
